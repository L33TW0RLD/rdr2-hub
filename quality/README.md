# Product Verification & Readiness

**Status:** QUALITY CONTRACT / PROPOSAL · 2026-10-17

The Hub must be correct **and** pleasant to use. Both qualities have independent verification gates.

Read [Acceptance Matrix](acceptance_matrix_v1.md) before accepting a research package, integrated activity, dashboard interaction or mission-to-Atlas return.

**Evidence ladder:** a documented example is not a live UI test; a user-reported UI pass proves only the observed client behavior; a rendered checkbox never proves a game action; an agent branch commit is not an approved mechanic. Verified GitHub readback is mandatory before a task is called delivered.

No test updates the old `rdr2/campaign/` without GameGuide authorization and actual player evidence.
