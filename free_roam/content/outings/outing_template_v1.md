# OUTING Authoring Template v1

**Status:** TEMPLATE ONLY · not an initiated or completed expedition.

- **ID / version:** FR.OUTING.<slug> / 0.1 (illustrative)
- **Maturity / scope / spoiler tier:** DRAFT · Story Mode · T0/T1
- **General prerequisites:** location access, horse/tool/system access **conditional**
- **Live checks:** actual player area, available tools, time-sensitive active risk; all UNKNOWN until reported/read
- **Related PROJECT, Atlas and optional Mission path:** link to exact source + status

## Invitation

**Why go?** A motivating 1–2 sentence proposal, not a completion quota.

## Optional organic sequence

1. **Depart:** a small verified/conditional preparation; don't mandate three menu checks when none affect safety.
2. **Explore:** one meaningful observation or skill; keep choice of route/player curiosity.
3. **Try:** a repeatable mechanic with accurate warning about quality, consumables and prerequisites.
4. **Discover:** allow unexpected events without spoiled locations or mandatory pickup.
5. **Return:** one possible handoff to camp/vendor/story; actual rewards/items remain UNKNOWN unless observed.

## Outcomes, not invented progress

- **Satisfying even if empty-handed:** specific experience/lesson.
- **Possible material or project milestone:** only after player actually reports evidence.
- **Consequential caution:** specific, actionable, source-backed; keep out of an optional drawer if urgent.
- **Player report prompt:** short and event-specific only after something happens.

## Sources / conflicts / Atlas

Write a source claim ledger where exact weapon, price, recovery, Honor, chapter access or irreversible loss matters. Separate generalized mechanics from equipment that the user definitely has. Avoid guaranteed spawn sites and exact distances without independent checks.

**Acceptance:** plausible local outing, organic choice, one related mechanic, no invented inventory or completion, independent reward from project grind.
