# INTERMISSION Context Template v1

**Status:** TEMPLATE ONLY; window activation is a live GameGuide/player-state question, never an automatic mission-completion ritual.

## Trigger and control gate

- **After which reported event or player's request?** Must be explicit; no automatic "after every Gold".
- **Current control:** FREE_ROAM / CAMP_ONLY / CHAINED_MISSION / UNKNOWN.
- **Available story markers:** observed set or UNKNOWN; do not infer from mission shelf numbering.
- **Credible urgent risk:** precise source-backed active stage, not speculative next-chapter anxiety.
- **Current player interest:** optional project, "just explore", mission, or UNKNOWN.

If **CHAINED_MISSION**, hand back to full Mission Control, no intermission. If UNKNOWN, offer conditional choices or ask one useful observation rather than claiming open world freedom.

## Dashboard material (when free roam exists)

**PROJECT:** one player-aligned longer-term capability, a meaningful conditional milestone, one supporting mechanic.

**OUTING:** one organic local adventure with a why-now explanation and an expected fun/learning outcome even without a material reward.

**DISCOVERY:** one neutral prompt to engage unexpected encounters without pre-spoiling map locations.

**STORY:** one always-available route back to a genuinely player-confirmed/selectable mission (or ask which marker is visible).

**ALTERNATIVES:** at most two distinct choices; omit if no credible alternatives.

## Preserve and finish

- Only show a now-or-never warning if triggered **and** supported; classify `NOW / BEFORE LEAVING / CAN WAIT`.
- Honor, Gold, unique items, mission chains and save-window safety remain GameGuide's domain.
- Upon new player report: re-read canonical records and adjust the next proposed outing; no checklist completion from UI clicks.
- Record source references, maturity and unknown gates in the authoring record.

**Acceptance:** respects player's chosen pace, conditional unlocks, relevant mission control window and no automatic forced objective/cadence.
