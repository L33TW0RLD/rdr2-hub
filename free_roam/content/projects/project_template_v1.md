# PROJECT Authoring Template v1

**Status:** TEMPLATE ONLY · not a registered player objective. Save an authored PROJECT as a separate file under `free_roam/content/projects/`; do not overwrite this template.

## Metadata

- **Record ID / version:** FR.PROJECT.<slug> / v0.1 (illustrative namespace, not ratified)
- **Maturity:** DRAFT / RESEARCHED_REVIEW_PENDING / ADOPTED
- **Spoiler scope:** Story Mode T0/T1 default
- **Owner / date / evidence status:** required
- **Related mechanic IDs:** source-backed Sxx.Mnn refs, each maturity retained
- **General unlock gates:** conditional with accurate source, never "already unlocked"
- **Current player commitment:** NOT STORED HERE; session intent only unless canonical report exists

## Player promise

One sentence: "This project is worth spending some of Arthur's time on because ..."

### Milestones (not mandatory shopping quotas)

| Conditional milestone | Player-observable completion proof | Practical benefit | General gate |
|---|---|---|---|
| First capability milestone | Exact in-game UI or player report | Relevant improvement, not a fabricated score | Sourced or UNKNOWN |
| First useful application | Player-observed outcome | Optional next step | Sourced or UNKNOWN |
| Later milestone | Optional, can wait | Reason to revisit | Conditional |

### Suggested outings

1. One natural outing, with **why now**, approximate local context and what to notice.
2. A genuinely different alternative (not a disguised grind).
3. An immersive pause or direct return to Story.

### Adaptation and preservation

- What discovery would appropriately interrupt or redirect the project?
- What specific, evidenced active one-off risk should outrank it?
- What is the safe fallback when an unlock or inventory state is unknown?
- What is learned or enjoyable even if no materials are obtained?

### Source ledger and handoff

Cite each claim requiring precision. State conflicts and status. GameGuide owns any eventual report; dashboard chooses presentation, not facts.

**Minimum acceptance:** meaningful objective, optional next milestone, no invented player state, at least one feasible-if-confirmed outing, source-aware mechanic links, explicit preservation warning only if warranted.
