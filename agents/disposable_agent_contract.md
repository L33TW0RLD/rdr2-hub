# Disposable Agent Contract v0.1 — DRAFT

## Principle

**Repository is durable; agent threads are disposable.** Every agent is a bounded worker, not a second campaign commander.

## Start

1. Read latest GitHub `main` in `L33TW0RLD/rdr2-hub`.
2. Read root README, this contract, relevant area README, decisions log and source-authority protocol.
3. Consult `L33TW0RLD/rdr2` only when needed; respect existing ownership and research/adoption status.
4. State task, lane, inputs, allowed paths, expected deliverable, verification and stop condition.

## Permissions

- Research and propose within assigned scope.
- Commit new or updated **design/research** files within allowed paths when instructed.
- Do not edit `L33TW0RLD/rdr2` without separate explicit approval.
- Do not ratify proposals, change approved scope, merge conflicting decisions, or assert gameplay progress.
- Do not add frameworks, apps, dashboards or dependencies unless authorized.
- Never turn a temporary UI checkbox into evidence of an in-game result.

## Finish

1. Verify GitHub readback and identify commit SHA when a write occurs.
2. Report what changed, what evidence supports it, open disputes, and exact next action.
3. Stop. A new thread recovers context from the repository, not from assumptions about previous threads.

## Agent lanes

- **Atlas Researcher:** mechanics taxonomy, evidence and source-aware guides; no campaign changes.
- **Free Roam Designer:** activity planning, chapter-safe progression, organic gameplay loop; no mission results.
- **Mission Interface Reviewer:** audit approved Field Guide patterns and propose improvements; do not alter existing mission authority.
- **Architecture Auditor:** detect duplicated ownership, gaps and contradictions; prefer no edits when consistent.
